# 数据如何流动

DreamTravel 当前采用用户自带凭据（BYOK）的直连原型。仓库没有内置公共服务端，也不附赠 API 额度。

| 数据 | 保存／接收方 | 用途 |
| --- | --- | --- |
| DeepSeek API Key | 设备 Keychain；请求时发往 DeepSeek | 模型调用鉴权 |
| 腾讯 WebService Key | 设备 Keychain；请求时发往腾讯位置服务 | 地点、路线和天气查询 |
| 城市、本次描述、规划上下文 | DeepSeek | 搜索、整理与结构化规划 |
| 地点名称、坐标、路线起终点 | 腾讯位置服务 | 查找地点并计算交通、天气 |
| 用户启用的参考资料 | App 私有 Application Support 目录；生成使用时相关片段进入模型上下文 | 后续规划复用 |
| 商家网页／预约页面 | 用户打开的第三方平台 | 查看信息或自行预订 |

资料库是 App 私有目录中的版本化 JSON 文件，并非额外加密数据库。设置中可以关闭主动搜索、地点研究、自动积累和生成时使用资料库，也可以编辑、停用或删除参考条目。

没有承诺所有内容只留在手机上。调用模型、地图、搜索与商家网页都会发生网络通信，并受相应服务商条款及隐私政策约束。需要隐私保护时，不要在自由描述中输入姓名、电话、私人地址或其他无关的敏感信息。

Debug 联调可能在设备私有目录或临时目录写入规划结果、供应商响应和诊断文件。这些文件不应上传到公开仓库。`Validation/` 和 Xcode 用户配置已加入忽略规则，发布检查也会拒绝把它们纳入 Git。

MIT 许可证覆盖项目代码和自制文档素材，不授予任何第三方地图数据、商家照片、帖子全文或品牌素材的再分发权。App 的预约入口仅交接到平台；不代替用户登录、下单或支付。
